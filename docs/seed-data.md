# 시드 데이터 (로컬 개발용)

`pnpm db:seed`로 넣는 데모 데이터 정리. 원본은 [`apps/server/prisma/seed.ts`](../apps/server/prisma/seed.ts)다.
이름·연락처·주소는 모두 **가상 데이터**다.

## 한눈에 보기

| 구분   | 데모 방문간호센터 (`DEMO-001`)     | 데모 재택의료의원 (`DEMO-002`)                |
| ------ | ---------------------------------- | --------------------------------------------- |
| 사업   | 장기요양 방문간호                  | 일차의료 방문진료, 장기요양 재택의료센터      |
| 계정   | 기관 관리자 1, 간호사 2            | 기관 관리자 1, 의사 1, 간호사 1, 사회복지사 1 |
| 수급자 | 5명                                | 3명                                           |
| 방문   | 5건 — 어제 확정 1건, 오늘 예정 4건 | 5건 — 어제 확정 1건(서식 2장), 오늘 예정 4건  |

운영자 `admin` 1개는 기관에 속하지 않는다. 비밀번호는 모든 계정 **`1234`**.

## 계정

| 아이디     | 이름   | 역할 (직종)                    | 면허·자격번호 | 소속                  | 로그인할 곳      |
| ---------- | ------ | ------------------------------ | ------------- | --------------------- | ---------------- |
| `admin`    | 운영자 | 운영자 (ADMIN)                 | —             | 없음 (전체 기관 관리) | 관리 웹          |
| `manager`  | 김관리 | 기관 관리자 (MANAGER)          | —             | 데모 방문간호센터     | 관리 웹, 현장 웹 |
| `nurse1`   | 이간호 | 현장 직원 (STAFF · 간호사)     | N-100001      | 데모 방문간호센터     | 현장 웹          |
| `nurse2`   | 박간호 | 현장 직원 (STAFF · 간호사)     | N-100002      | 데모 방문간호센터     | 현장 웹          |
| `manager2` | 한관리 | 기관 관리자 (MANAGER)          | —             | 데모 재택의료의원     | 관리 웹, 현장 웹 |
| `doctor1`  | 정의사 | 현장 직원 (STAFF · 의사)       | D-200001      | 데모 재택의료의원     | 현장 웹          |
| `hnurse1`  | 오간호 | 현장 직원 (STAFF · 간호사)     | N-200002      | 데모 재택의료의원     | 현장 웹          |
| `social1`  | 윤복지 | 현장 직원 (STAFF · 사회복지사) | S-200003      | 데모 재택의료의원     | 현장 웹          |

- 비밀번호는 모두 `1234`.
- 현장 웹: http://localhost:5210 · 관리 웹: http://localhost:5211
- 두 기관 관리자는 직종이 없어 방문을 맡지 않는다. 현장 웹에 로그인은 되지만 본인 방문이 없다.
- 시드를 다시 실행하면 시드 계정의 비밀번호가 `1234`로, 역할·직종·소속·사용 상태가 위 표대로 되돌아간다.
- `1234`는 시드 계정에만 쓰는 값이다. 관리 웹에서 새로 만들거나 재설정하는 비밀번호는 **8자 이상** 규칙이 그대로 적용된다.

## 다시 넣기·초기화

| 하고 싶은 것                                         | 명령                                                                  |
| ---------------------------------------------------- | --------------------------------------------------------------------- |
| 시드 계정 비밀번호만 `1234`로 되돌리기               | `pnpm db:seed`                                                        |
| 전부 지우고 처음 상태로 (오늘 날짜로 방문 다시 생성) | `pnpm infra:reset && pnpm infra:up && pnpm db:deploy && pnpm db:seed` |

- 시드는 여러 번 실행해도 중복되지 않는다. 기관은 기관 코드로, 계정은 아이디로 찾아 재사용하고(기관의 사업 목록도 시드대로 되돌린다), 수급자는 기관에 한 명도 없을 때만, 방문은 기관에 한 건도 없을 때만 만든다.
- 그래서 **날짜가 바뀌면 "오늘" 방문이 자동으로 생기지 않는다.** 오늘 날짜로 다시 보고 싶으면 위의 초기화를 실행한다.
- `infra:reset`은 이 레포의 DB 볼륨(`carenote_carenote-pg`)만 지운다. 구 `_carenote`의 컨테이너·데이터는 건드리지 않는다.
